## Why

Teams patching many servers need one clear view of which hosts are behind and an alert when that matters.

## What I built

- Policy rules for patch compliance
- Reports and an HTML page from fleet data
- Terraform modules and per-environment configuration

## How it is checked

- pytest suite for policy, report and page output
- Runs on synthetic fleet data only
